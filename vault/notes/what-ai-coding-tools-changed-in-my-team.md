# What AI coding tools changed in my team

We've used AI coding assistants on my team for over a year now. The honest summary: they made good habits more valuable and bad habits more expensive.

Engineers who break work into small, clear tasks get great results. The assistant writes the boilerplate, suggests tests and catches silly mistakes. Engineers who start with a vague goal get large, plausible-looking changes that are hard to review and sometimes subtly wrong.

So we changed how we work, not just which tools we use. Every task starts with a short written intent: what should change and how we'll know it worked. Pull requests stay small. Reviewers ask the author to explain any AI-written code they don't fully understand. And we keep a shared file of instructions for the assistant, describing our conventions, so it writes code that fits.

AI didn't replace engineering judgement. It raised the price of not having it.
