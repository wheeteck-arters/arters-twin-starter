# Code review is not a gate, it's a conversation.

Code review is not a gate, it's a conversation. When my team started treating reviews as 'approve or block', cycle time went up and trust went down. We changed one thing: every review must start with what the author did well and one question before any request. Within a month, median review time dropped from 26 hours to 9, and people started asking for reviews earlier instead of hiding big pull requests.
