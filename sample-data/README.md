# Sample data: Mei Lin Chua (made up)

Mei Lin is a fictional engineering lead in Singapore. Use her writing on Day 1 if your own
LinkedIn export hasn't arrived yet: `npm run ingest:sample`. Swap in your own data later.

- `linkedin/` mimics the LinkedIn "full archive" export: Profile.csv, Shares.csv, Articles/Articles/*.html.
  A real export also has Connections.csv. The starter never reads it (other people's data, PDPA).
- `writing/` holds blog essays as Markdown, like a Substack or Ghost export.
